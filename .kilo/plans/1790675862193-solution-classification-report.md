# 24 点有解题目解法归类汇总计划

## 目标

基于 `results/solutions.txt` 中 1362 个有解组合的全部解, 按解法套路归类, 生成汇总报告 `results/classification.md` (全量清单 + 统计)。

## 已确认决策 (与用户对齐)

- **分类口径**: 标准六类套路 (直乘 / 连乘 / 凑乘数 / 乘后调整 / 除法 / 分数), 另设「其他」兜底 — 纯加减解确实存在 (如 6+6+6+6、13+13-1-1), 六类装不下。
- **报告组织**: 每类一章 (套路定义 + 公式模板 + 典型例题 + 该类组合全量清单), 开头放总览统计表。

## 现状要点

- `solver.py` 已提供 `solve_trees(cards)` (返回 {规范化串: 表达式树})、`evaluate(tree)` (Fraction 精确求值)、`_fmt(tree)` (最小括号格式化), 全部复用, **不修改 solver.py**。
- `solutions.txt` 每行 `组合 | 解数 | 解1; 解2; ...`, 存在视觉重复解 (如 `12*(1+1)/1` 与 `12*(1+1)` 同义异形、`8*(1+2/1)` 与 `8*(1+2)` 同义), 归类前必须化简去重, 否则统计失真。
- `results/` 已被 `.gitignore` 忽略, 报告属于生成物。
- 测试风格: `test_solver.py` 纯 assert + 直接运行。

## 实现

### 1. 新建 `classify_solutions.py` (项目根目录, 风格与 solve_all.py 一致, 中文 docstring)

数据流: `solve_trees(cards)` 取表达式树 → 化简 → 去重 → 逐解分类 → 定组合主类 → 生成 Markdown。

### 2. 化简与去重

- `simplify(tree)` 递归化简: `x*1→x`、`x/1→x`、`x+0→x`、`x-0→x`。
- 化简后按 `_canon` 风格规范化串作为去重 key; 每个等价类保留最短字符串为**代表解**。

### 3. 单解分类规则 (按序判定, 取首个命中)

1. **F 分数型**: 任一子树求值为非整数 (例 `8/(3-8/3)`)。
2. **E 除法型**: 树中含 `/` 且中间值全为整数 (例 `6*8/(1+1)`、`12/((1+1)/4)`)。
3. **B 直乘型**: 纯乘树, 化简后恰 2 个因子 (例 `3*8`、`12*2`)。
4. **A 连乘型**: 纯乘树, 化简后 ≥3 个因子 (例 `1*2*3*4`、`2*2*6`)。
5. **C 凑乘数型**: 顶层 `*` 且至少一侧因子是纯加减子树 (例 `(1+11)*(1+1)`、`12*(3-1)`、`(1-13)*(1-3)`)。
6. **D 乘后调整型**: 顶层为加减链且链中含乘/除子树 (例 `3*8+1-1`、`5*5-1`、`13*(1+1)-2`)。
7. **其他**: 纯加减树等 (例 `6+6+6+6`、`13+13-1-1`)。

注: F 先于 E 判定, 保证 `8/(3-8/3)` 这类经典分数题归 F。F 类会含少量"形式分数"解 (如 `1/(1/(2*12))`), 组合级主类不受影响, 报告中注明口径。

### 4. 组合级归类

- 组合的**可用套路** = 该组合全部去重解的类别集合。
- 组合**主类** = 按"从简到繁"优先级取最简: `B > A > C > D > 其他 > E > F`。
- 清单行格式: `组合 | 去重解数 | 可用套路缩写 | 代表解` (代表解取主类解中最短者)。

### 5. 报告结构 `results/classification.md`

- 说明: 数据来源、化简去重口径、分类口径。
- 总览表: 类别 | 定义/公式模板 | 主类组合数 | 覆盖组合数(该类出现在其任一解中) | 典型例题。
- 六类 + 其他各一章: 套路说明、2-3 个典型例题、该主类组合全量清单表。
- 末尾: 与 `summary.txt` 核对说明 (1362 个有解组合全覆盖; 去重后解总数与 13456 的差异说明)。

### 6. 测试 (追加到 `test_solver.py`)

- `(3,3,8,8)` 主类 = F。
- `(1,1,3,8)` 可用套路含 B (`3*8`)。
- `(1,1,1,13)` 主类 = C (`(13-1)*(1+1)`)。
- `(6,6,6,6)` 解集中同时含 D (`6*6-6-6`) 与纯加减解。
- 全组合扫描: 每个有解组合至少归入一个类别; 每个组合的代表解 `evaluate == 24`。
- `python test_solver.py` 全部通过。

### 7. 验证

- 运行 `python classify_solutions.py`, 生成报告并打印统计。
- 抽查: `3,3,8,8` 出现在 F 章; `1,2,3,4` 出现在 B 章 (1*2*3*4 化简后 4 因子 → A, 按实际归类核对); 报告组合总数 = 1362。
- 交叉核对: 各类主类组合数之和 = 1362。
